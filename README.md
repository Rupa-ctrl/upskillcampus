# Secure Password Manager using Python

## Project Overview
This project is a Secure Password Manager developed using Python. It allows users to securely store and manage passwords for different websites and applications.

## Features
- Add Password
- View Passwords
- Search Password
- Update Password
- Delete Password

## Technologies Used
- Python
- JSON
- File Handling

## How to Run

python main.py
